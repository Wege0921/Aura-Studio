## Getting Started

### Accessing the Platform

Visit **[https://aurastudio.et](https://aurastudio.et)** to access the AURA Studio web application. The platform is fully responsive and works on desktop, tablet, and mobile devices.

### Creating an Account

1. Click the **"Sign Up/Login"** button in the top right corner of the homepage
2. Enter your email address and create a password
3. You'll receive an email to verify your account
4. Click the verification link to complete registration

### Logging In

1. Click **"Log In"** in the top right corner
2. Enter your email and password / Continue with Google
3. Your login session is saved — you won't need to log in again when you return to the site

### Resetting Your Password

If you forget your password:
1. Click **"Log In"** → **"Forgot Password?"**
2. Enter your email address
3. Check your email for a password reset link
4. Create a new password using the link

## Browsing and Booking Classes

### Viewing Available Classes

1. Navigate to the **"Classes"** page from the main menu
2. You'll see a list of all available classes with details including:
   - Class name and description
   - Instructor name
   - Date and time
   - Duration
   - Available spots
   - Price
   - Class type (Pilates, Prenatal, Postpartum)

### Filtering Classes

Use the filter options to find classes that match your preferences:
- **Date**: Filter by specific dates
- **Class Type**: Choose from Pilates, Prenatal, or Postpartum
- **Instructor**: Filter by your preferred instructor
- **Price**: Filter by price range

### Booking a Class

1. Click on a class card to view more details
2. Click **"Book Now"** button
3. Select your payment method:
   - **Package Session**: Use an existing package (if you have active sessions)
   - **Bank Transfer**: Upload a payment receipt
   - **Mobile Money**: Upload a payment receipt
   - **Cash**: Pay at the studio
4. Complete the booking process

### Booking with a Package

If you have purchased a package with remaining sessions:
1. Select **"Use Package Session"** when booking
2. Choose which package to use (if you have multiple)
3. One session will be automatically deducted from your package
4. Your booking is immediately confirmed as paid

### Booking Status

- **CONFIRMED**: Your booking is secured and payment is verified
- **PENDING**: Your booking is awaiting payment verification (for bank transfer/mobile money)
- **CANCELLED**: You have cancelled this booking

## Packages and Pricing

### What Are Packages?

Packages are prepaid bundles of class sessions that offer better value compared to individual bookings. They come in different sizes and may be specific to certain class types.

### Viewing Available Packages

1. Navigate to the **"Packages"** page from the main menu
2. Browse available packages showing:
   - Package name and description
   - Number of sessions included
   - Price
   - Validity period (if applicable)
   - Applicable class types

### Purchasing a Package

1. Click on a package card to view details
2. Click **"Purchase Package"**
3. Select your payment method:
   - **Bank Transfer**: Upload your payment receipt
   - **Mobile Money**: Upload your payment receipt
4. Submit your payment information
5. Your package will be activated once payment is verified by admin

### Package Validity

Some packages have an expiration date. Make sure to use your sessions before the package expires. You can view your package's expiry date in your dashboard.

### Using Package Sessions

When booking a class, if you have active packages:
- The system will show your available packages
- Select the package you want to use
- One session will be deducted from that package
- You can track remaining sessions in your dashboard

## Payment Methods

### Available Payment Options

#### 1. Package Session
- Use sessions from a pre-purchased package
- Instant confirmation — no waiting for verification
- Best value for regular attendees

#### 2. Bank Transfer
- Transfer payment to the studio's bank account
- Upload a screenshot/photo of your payment receipt
- Booking status remains "PENDING" until admin verifies payment
- You'll receive confirmation once verified

#### 3. Mobile Money
- Pay via mobile money service
- Upload a screenshot of your transaction confirmation
- Booking status remains "PENDING" until admin verifies payment

#### 4. Cash
- Pay in person at the studio
- Booking is confirmed immediately
- Bring exact change when possible

### Payment Verification

For bank transfer and mobile money payments:
- Admin receives an automatic notification with your payment receipt
- Payments are typically verified within 24 hours
- Check your dashboard for booking status updates

## Managing Your Bookings

### Viewing Your Bookings

1. Go to your **Dashboard** (accessible from the main menu when logged in)
2. Scroll to the **"My Bookings"** section
3. You'll see all your bookings with status indicators

### Cancelling a Booking

You can cancel a booking if:
- The class hasn't occurred yet
- It's at least 2 hours before the class start time

**To cancel:**
1. Go to your Dashboard
2. Find the booking you want to cancel
3. Click **"Cancel Booking"**
4. Confirm the cancellation

**What happens when you cancel:**
- If you used a package session, the session is refunded to your package
- If you paid individually, you may receive a refund (contact admin)
- If the class is full, the next person on the waitlist is automatically promoted

### Booking History

Your dashboard shows all your past and upcoming bookings, making it easy to track your class attendance history.

## Waitlist

### Joining the Waitlist

When a class is fully booked:
1. The class card will show **"Fully Booked"**
2. A **"Join Waitlist"** button will appear
3. Click the button to add yourself to the waitlist
4. You'll be notified if a spot becomes available

### How the Waitlist Works

- When someone cancels a booking, the first person on the waitlist is automatically promoted
- Your booking will be confirmed automatically
- If you used a package session for the waitlist, it will be deducted when promoted

### Leaving the Waitlist

If you no longer want to wait for a class:
1. Go to your Dashboard
2. Find the waitlisted class
3. Click **"Leave Waitlist"**

## For Admin/Studio Owners

### Accessing the Admin Panel

Admin users have access to a comprehensive management panel. If you're an admin, you'll see an **"Admin"** option in the main menu.

### Admin Dashboard Overview

The admin dashboard provides:
- **Total Users**: Number of registered users
- **Total Classes**: Active classes in the system
- **Total Bookings**: All bookings made
- **Total Revenue**: Revenue from confirmed payments
- **Active Packages**: Currently active user packages
- **Pending Payments**: Payments awaiting verification

### Managing Classes

#### Creating a Class
1. Go to **Admin → Classes**
2. Click **"Add New Class"**
3. Fill in class details:
   - Class name and description
   - Instructor
   - Date, time, and duration
   - Capacity
   - Class type
   - Price
4. Save the class

#### Editing/Deleting Classes
- Click on a class to edit its details
- Delete classes that are no longer relevant
- Classes cannot be deleted if they have active bookings

### Managing Bookings

#### Viewing All Bookings
- Go to **Admin → Bookings**
- See all bookings with user details, class information, and payment status
- Filter by status (Confirmed, Pending, Cancelled)

#### Approving Payments
1. Find pending bookings
2. Review the uploaded payment receipt
3. Click **"Approve Payment"** to confirm
4. The user receives automatic notification

#### Rejecting Payments
1. Find pending bookings
2. Click **"Reject Payment"**
3. Optionally provide a reason
4. The user receives notification and can re-upload

### Managing Packages

#### Creating Packages
1. Go to **Admin → Packages**
2. Click **"Add New Package"**
3. Define:
   - Package name and description
   - Number of sessions
   - Price
   - Validity period (optional)
   - Applicable class types
4. Save the package

#### Viewing User Packages
- See all packages purchased by users
- Track remaining sessions and expiry dates
- Manually adjust sessions if needed (for special cases)

### Managing Payments

#### Payment Overview
- Go to **Admin → Payments**
- View all transactions
- Filter by status (Paid, Pending, Failed)
- See payment amounts and methods

### Managing Users

#### User Management
1. Go to **Admin → Users**
2. View all registered users
3. See user roles (Regular/Admin)
4. Promote users to admin if needed
5. View user booking and package history

### Managing Instructors

#### Instructor Profiles
1. Go to **Admin → Instructors**
2. Add new instructors with their details
3. Assign instructors to classes
4. Manage instructor availability

### Analytics

#### Performance Insights
- Go to **Admin → Analytics**
- View booking trends over time
- See revenue breakdown
- Track class popularity
- Monitor user engagement

## Frequently Asked Questions

**Q: Can I book a class for someone else?**
A: Currently, bookings are tied to your account. Each user must have their own account to book classes.

**Q: What happens if I miss a class?**
A: If you don't cancel at least 2 hours before the class, you forfeit the session or payment. No-shows cannot be refunded.

**Q: Can I transfer my package to someone else?**
A: Packages are non-transferable and tied to your account.

**Q: How do I know if my payment was verified?**
A: Check your dashboard for booking status updates. You'll also receive an email confirmation when payment is approved(comming soon).

**Q: What if the class is cancelled by the studio?**
A: If we cancel a class, you'll receive a full refund or your package session will be restored.

**Q: Can I get a refund for a package?**
A: Package refunds are handled on a case-by-case basis. Contact us to discuss your situation.

**Q: How long do waitlists stay active?**
A: Waitlists remain active until the class occurs. If a spot opens up, the first person on the waitlist gets it.
